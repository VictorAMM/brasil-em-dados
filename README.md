# Brasil em Dados

Site estático com três leituras de longo prazo sobre o desenvolvimento brasileiro:

- **[Atlas do desenvolvimento — 1996–2026](desenvolvimento-brasil-1996-2026.html)** — 48 fatos estruturantes, 6 eras, 9 forças, 8 cadeias causais e a posição do Brasil no mundo.
- **[Composição do PIB — 1995–2025](composicao-pib-brasil-1995-2025.html)** — oferta (agro, indústria, serviços, impostos) e demanda (famílias, governo, FBCF, setor externo), ano a ano, com tabela e CSV.
- **[Investimento (FBCF) — 1995–2025](investimento-brasil-1995-2025.html)** — formação bruta de capital fixo, investimento público e privado e o gap de infraestrutura.

**Publicado em:** https://victoramm.github.io/brasil-em-dados/

## Estrutura

```
index.html                              # página inicial
desenvolvimento-brasil-1996-2026.html  # atlas
composicao-pib-brasil-1995-2025.html   # composição do PIB
investimento-brasil-1995-2025.html     # relatório de investimento
.nojekyll                              # desativa o processamento Jekyll
```

As páginas são autossuficientes: HTML, CSS e JavaScript próprios; os gráficos são SVG gerados no navegador. A única dependência externa é o Google Fonts.

## Fontes

IBGE, Ipea, Banco Central, World Bank, FMI, OCDE, PNUD, INPE/PRODES, MapBiomas, OMS, Unesco e FAO. Cada relatório traz a metodologia, as ressalvas e a lista completa de fontes.
